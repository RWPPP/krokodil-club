БЕСПЛАТНЫЙ ВАРИАНТ С ПОДКЛЮЧЕНИЕМ ЧЕРЕЗ NETLIFY

Существующую базу Supabase и список администраторов менять не нужно.

1. Загрузите содержимое архива в корень существующего GitHub-репозитория:
   netlify.toml
   public/index.html
   netlify/functions/club-api.mjs
   README_NETLIFY.txt
   Папки public и netlify должны находиться рядом с прежним index.html.
   Прежний корневой index.html не заменяется: GitHub Pages продолжит работать как раньше.

2. Откройте https://app.netlify.com/signup и войдите через GitHub.
   Выберите бесплатный тариф Free.
   Add new project → Import an existing project → GitHub → RWPPP/krokodil-club.
   Если отображается Add new site, выберите Import an existing project.
   Branch: main.
   Base directory: пусто.
   Build command: пусто.
   Publish directory: public.
   Functions directory: netlify/functions.
   Конфигурация netlify.toml уже содержит необходимые папки.
   Нажмите Deploy / Publish.
   Не используйте Drag and drop: для серверной функции нужен импорт Git-репозитория.

3. Откройте полученную ссылку *.netlify.app БЕЗ VPN.
   Проверьте загрузку страницы и надпись «Общая база».
   Проверьте также мобильный интернет.
   Если сайт не открывается или база недоступна, сообщите результат.
   Нельзя гарантировать доступность Netlify из конкретной сети до этой проверки.

4. Войдите в админку с прежним email и паролем.
   Записи остаются в той же базе и появятся на соответствующей неделе.
   На новом адресе потребуется войти заново.
   Анонимные сессии привязаны к адресу: прежние заявки гостя будут видны администратору,
   но у гостя на новом адресе создастся новая сессия.

Как работает:
Браузер обращается только к домену нового сайта. Серверная функция Netlify
передаёт четыре вида запросов в существующий Supabase: гостевой вход,
вход/обновление сессии, выход и действия клуба.
Произвольные адреса и прямые запросы к таблицам не разрешены.
Права администратора и вместимость всё ещё проверяются базой.
Пароли и токены передаются по HTTPS; функция их не записывает в логи.

Free имеет месячный лимит, а не безлимитное использование.
Текущие условия: https://www.netlify.com/pricing/
Не включайте платный тариф ради этого запуска. При исчерпании бесплатного
лимита доступ может быть приостановлен до восстановления лимита.
Сайт обновляет данные каждые 2 минуты и при возврате во вкладку.

Локально проверены обработка маршрутов, передача сессии, ошибки и JavaScript.
Работа функции в Netlify и доступ без VPN проверяются после публикации.
