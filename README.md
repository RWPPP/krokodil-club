Сайт для записи студентов-участников Музыкального Клуба на занятия.

Доступ идёт только по ссылке, которая распространяется только среди членов клуба.

Функционал для студента:
Авторизация через VK ID, через специально созданное внутреннее приложение VK.
Запись на занятия по разным инструментам с выбором недели, даты, времени.
Личный кабинет студента со списком будущих записей.
В личном кабинете студента реализована функция "Серии" - если студент не пропускает занятия "огонёк серии" продолжает "гореть".

Функционал учётной записи администратора:
Авторизация через email
Подтверждение записи студента
Сводка расписания
Ручное и автоматическое распределение
Инструменты для смены оформления сайта

Сайт реализован через GitHub Pages, серверная часть - Render, база данных - на Supabase
